
# TryHackMe – OFFENSIVE SECURITY INTRO

## OVERVIEW

I completed the Offensive Security Intro room on TryHackMe.

This room introduced me to the basics of offensive security and ethical hacking. I learned how attackers can identify weaknesses in websites and how security professionals can test systems legally in a safe environment.

## WHAT I LEARNED

- What offensive security means
- The difference between offensive and defensive security
- Basic concepts of ethical hacking
- How attackers look for vulnerabilities
- How to interact with a website from a security perspective
- The importance of performing security testing legally and responsibly

## PRACTICAL EXPERIENCE

One of the main activities involved interacting with a website in a controlled TryHackMe environment. This helped me understand how security testing works in practice rather than just reading about it.

## KEY TAKEAWAY

This room gave me a good introduction to offensive security and made me more interested in learning penetration testing and vulnerability assessment.
